Forgelink

Forgelink is a small personal Android app. Once a day (or on demand) it copies the user's own daily data from Health Connect (weight, steps) and Kalorické tabulky (calories, protein, carbs, fat, fiber) into a Google Sheet the user chooses, so it no longer has to be typed in by hand.

It is built for personal use by its author; it is not distributed through any app store and has no server component.

Česky

Forgelink je malá osobní aplikace pro Android, která kopíruje vlastní denní data z Health Connect (váha, kroky) a Kalorických tabulek (kalorie, makroživiny, vláknina) do zvolené tabulky Google. Není v žádném obchodě a nemá žádný server. Zásady ochrany osobních údajů.
