Privacy policy

Last updated: 16 October 2026

Forgelink is a personal Android app that copies the user's own daily health and nutrition values into a Google Sheet the user chooses. It has no backend server, no analytics, no advertising and no third-party tracking. The developer receives no data from the app.

Data the app accesses

  • Health Connect — weight and step count, read-only, only for the days being synced.
  • Kalorické tabulky — the daily totals of calories, protein, carbohydrates, fat and fiber from the user's own account, using the login the user enters in the app.
  • Google account — via Google Sign-In, with these permissions:
    • https://www.googleapis.com/auth/spreadsheets — to read the layout of the spreadsheet the user selected and write the synced values into it. Other spreadsheets are not read or changed.
    • https://www.googleapis.com/auth/drive.metadata.readonly — only to list spreadsheet names in the in-app picker when the user chooses the destination sheet. File contents are not accessed through this permission.

How the data is used and shared

The values are sent only to the Google Sheet the user selected, using the user's own Google account. They are not sent anywhere else, not sold, and not used for any purpose other than filling in that sheet. People who already have access to that sheet (for example a coach the user shared it with) can see the values written there.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage on the device

Settings, a short sync history and a diagnostic log are stored only on the phone. The Kalorické tabulky login is kept in the Android Keystore–backed secure storage. Passwords and access tokens are never logged. App data is excluded from Android cloud backup.

Removing access and data

  • Disconnect Google in the app's settings, or revoke access at myaccount.google.com/permissions.
  • Revoke Health Connect permissions in the Health Connect settings.
  • Uninstalling the app deletes all data it stored on the phone. Values already written to the sheet stay there and can be edited in Google Sheets.

Contact

Questions can be raised via GitHub issues.

Česky — shrnutí

Forgelink nemá žádný server, analytiku ani reklamy a vývojář z aplikace nedostává žádná data. Aplikace čte váhu a kroky z Health Connect a denní součty z vašeho účtu Kalorických tabulek a zapisuje je pouze do tabulky Google, kterou si sami vyberete. Oprávnění k Disku Google slouží jen k zobrazení názvů tabulek při výběru. Nastavení a přihlašovací údaje zůstávají v telefonu (přihlášení do Kalorických tabulek v zabezpečeném úložišti); hesla ani tokeny se nikdy nelogují. Přístup lze kdykoli zrušit v nastavení aplikace, na myaccount.google.com/permissions nebo v Health Connect; odinstalací se smažou všechna data v telefonu.
